# 🌸 CycleCare

A modern menstrual cycle prediction web application built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

👉 https://sparkling-mousse-fdfb3c.netlify.app/

## ✨ Features

- 📅 Next Period Prediction
- 🥚 Ovulation Tracking
- 🌱 Fertile Window Estimation
- 📆 Interactive Calendar Visualization
- 🎨 Modern Glassmorphism UI
- ✨ Animated Result Cards
- 📱 Mobile Responsive Design
- ⚠️ Health Disclaimer for Irregular Cycles

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Use

1. Select your last period start date.
2. Enter your cycle length.
3. Click **Predict My Cycle**.
4. View predicted period date, ovulation date, fertile window, and calendar highlights.

## ⚠️ Disclaimer

This application provides estimates only and may be less accurate for users with irregular cycles, PCOS/PCOD, hormonal conditions, pregnancy, or recent menstrual changes. It is intended for educational and personal tracking purposes and should not be considered medical advice.
